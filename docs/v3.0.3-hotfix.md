# v3.0.3 Release Notes - Critical Hotfixes

## 🐛 Issues Fixed

### 1. **Container Size Not Updating**

**Problem**: `force-graph-container` not getting correct dimensions  
**Root cause**: Container ref not ready when dimensions calculated

**Solution**:
```typescript
// Added delay for DOM ready
const timeoutId = setTimeout(updateDimensions, 100)

// Check parent element as fallback
const width = containerRef.current.offsetWidth || parent?.clientWidth || 800
const height = containerRef.current.offsetHeight || parent?.clientHeight || 600

// Added minHeight
<div style={{ minHeight: '400px' }}>
```

**Result**: Container now reliably gets correct dimensions

---

### 2. **Labels Too Large (Unreadable)**

**Problem**: Labels overshadowing nodes
- Font size: 14px minimum (too large)
- No truncation → long labels overflow
- Text larger than node by 2-3x

**Solution**:
```typescript
// Smaller, proportional labels
const fontSize = Math.min(11, Math.max(9, 11 / globalScale)) // 9-11px range
ctx.font = `500 ${fontSize}px Sans-Serif` // Medium (not bold)

// Truncate long labels
const maxLabelWidth = size * 3 // Max 3x node size
if (textWidth > maxLabelWidth) {
  displayLabel = truncated + '...'
}

// Semi-transparent background (not opaque)
ctx.fillStyle = 'rgba(255, 255, 255, 0.85)'
```

**Before vs After**:
```
v3.0.2: 
  ⭕ (14px node)
  serviceaccount-very-long-name-here (14px label) ← TOO BIG

v3.0.3:
  ⭕ (14px node)
  serviceaccount-v... (9-11px label) ← Proportional
```

---

### 3. **Layout Switching Doesn't Apply**

**Problem**: Changing layout dropdown doesn't trigger re-layout  
**Root cause**: No simulation restart on layout change

**Solution**:
```typescript
// Restart simulation when layout changes
useEffect(() => {
  if (fgRef.current && graphData.nodes.length > 0) {
    console.log('🔄 [ForceGraph] Layout changed, restarting:', layout)
    
    setTimeout(() => {
      // Restart simulation
      fgRef.current.d3ReheatSimulation()
      
      // Auto zoom-to-fit
      if (autoFitEnabled) {
        setTimeout(() => {
          fgRef.current?.zoomToFit(400, 50)
        }, layout === 'grid' ? 100 : 2000)
      }
    }, 100)
  }
}, [layout, autoFitEnabled, graphData.nodes.length])
```

**Behavior**:
1. User selects new layout
2. Simulation restarts instantly
3. Nodes rearrange with animation
4. Auto zoom-to-fit after settling
