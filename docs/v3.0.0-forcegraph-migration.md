# v3.0.0 Release Notes - Force Graph Migration

## 🔄 Major Architecture Change: Cytoscape → React Force Graph

**Date**: 2025-11-20  
**Breaking Change**: Yes (internal only, API unchanged)  
**Migration Type**: Complete graph library replacement

---

## 🎯 Why Migrate?

### Persistent Issues with Cytoscape
1. **TypeError: can't access property "w", "h", "x1"**
   - Occurred during layout calculations
   - Required extensive workarounds (manual positioning)
   - Unstable across different filter scenarios

2. **Z-index rendering problems**
   - Nodes/edges invisible despite successful data load
   - Required complex CSS stacking context fixes

3. **Filter update issues**
   - Graph didn't update when namespace filters changed
   - Required page reload for changes to take effect

4. **Large bundle size**
   - Cytoscape + plugins: ~1020KB minified
   - Heavy dependency footprint

### Benefits of Force Graph
1. **Stability**: No TypeError crashes
2. **Performance**: 50% smaller bundle (500KB vs 1020KB)
3. **Simplicity**: Built-in force-directed layout
4. **React-first**: Better integration with React lifecycle
5. **Filters work instantly**: No rendering issues

## 🔧 Implementation Details

### Data Transformation
```typescript
// Transform API data to Force Graph format
const graphData = useMemo<GraphData>(() => {
  // Filter nodes by type
  const nodes: Node[] = propData.nodes
    .filter(node => nodeTypeFilters[node.type] !== false)
    .map(node => ({
      id: node.id,
      label: node.label || node.id,
      type: node.type || 'unknown',
      data: node.data || {},
    }))

  // Filter edges and ensure valid node references
  const nodeIds = new Set(nodes.map(n => n.id))
  const links: Link[] = propData.edges
    .filter(edge => 
      connectionTypeFilters[edge.type] !== false &&
      nodeIds.has(edge.source) && 
      nodeIds.has(edge.target)
    )
    .map(edge => ({
      source: edge.source,
      target: edge.target,
      type: edge.type || 'unknown',
      data: edge.data || {},
    }))

  return { nodes, links }
}, [propData, nodeTypeFilters, connectionTypeFilters])
```

### Custom Canvas Drawing
```typescript
const drawNode = (node: Node, ctx: CanvasRenderingContext2D, globalScale: number) => {
  const size = NODE_SIZES[node.type] || 5
  const color = NODE_COLORS[node.type] || NODE_COLORS.unknown
  const isSelected = selectedNode === node.id

  // Draw node circle
  ctx.beginPath()
  ctx.arc(node.x!, node.y!, size * (isSelected ? 1.5 : 1), 0, 2 * Math.PI)
  ctx.fillStyle = color
  ctx.fill()

  // Draw label
  const fontSize = 12 / globalScale
  ctx.font = `${fontSize}px Sans-Serif`
  ctx.fillText(node.label, node.x!, node.y! + size + fontSize)
}
```
