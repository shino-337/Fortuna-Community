# Archive – Tài liệu cũ / one-off

Thư mục này chứa tài liệu **đã lỗi thời** hoặc **one-off** (báo cáo sửa lỗi, phân tích tạm, task list cũ, báo cáo test theo ngày) để giữ lịch sử nhưng không làm rối cấu trúc tài liệu chính.

## Cấu trúc

| Thư mục | Nội dung |
|---------|----------|
| **fixes/** | Báo cáo sửa lỗi one-off (Postgres, disk, eviction, DNS, CVE sync, deploy fix, …) |
| **task-lists/** | TODO, PENDING_TASKS, UI_AND_PENDING_TASKS (đã xử lý hoặc outdated) |
| **analysis/** | Phân tích/debug cũ (dashboard analysis, migration audit report) |
| **test-results/** | Báo cáo test theo ngày (E2E-*, CLEAN-*, DEBUG-*, verify-after-deploy-*, …) |
| **implementation-plans/** | Kế hoạch triển khai đã hoàn thành hoặc superseded |

Tài liệu **đang dùng** nằm trong docs/01-getting-started/ … docs/08-tutorials/. Xem DOCS_STRUCTURE.md.
