# NATS Subject Hierarchy

**Date**: 2025-11-30  
**Status**: ✅ Standardized per Architecture Review Issue #2

---

## Overview

This document defines the standardized NATS JetStream subject hierarchy for KSAM event flow.

---

## Subject Hierarchy

### Raw Events (From Agent)

**Stream**: `ksam-raw`  
**Subjects**: `ksam.raw.{resource_type}`  
**Retention**: 1 hour  
**Purpose**: Raw inventory items from agents before normalization

**Subjects**:
- `ksam.raw.pods`
- `ksam.raw.serviceaccounts`
- `ksam.raw.roles`
- `ksam.raw.rolebindings`
- `ksam.raw.clusterroles`
- `ksam.raw.clusterrolebindings`

**Publisher**: Ingest API (from Agent gRPC stream)  
**Consumer**: Normalizer Worker (single durable consumer)

---

### Normalized Events (After Normalization)

**Stream**: `ksam-normalized`  
**Subjects**: `ksam.normalized.{resource_type}`  
**Retention**: 24 hours  
**Purpose**: Normalized and enriched inventory items

**Subjects**:
- `ksam.normalized.pods`
- `ksam.normalized.serviceaccounts`
- `ksam.normalized.roles`
- `ksam.normalized.rolebindings`

**Publisher**: Normalizer Worker  
**Consumers**: 
- Risk Worker (durable consumer)
- Correlator Worker (durable consumer)
- Policy Engine (future)
- Baseline Learner (future)

---

### Runtime Events

**Stream**: `ksam-events`  
**Subjects**: `ksam.events.runtime`  
**Retention**: 7 days  
**Purpose**: Runtime security events from eBPF

**Publisher**: Agent (eBPF events)  
**Consumers**: Policy Engine, Baseline Learner

---

### Insights

**Stream**: `ksam-insights`  
**Subjects**: `ksam.insights.created`  
**Retention**: 30 days  
**Purpose**: Risk insights generated by Risk Engine

**Publisher**: Risk Worker  
**Consumers**: Dashboard API, Webhook handlers (future)

---

## Event Flow

```
Agent (gRPC)
    ↓
Ingest API
    ↓ Publish: ksam.raw.{type}
┌─────────────────────┐
│ NATS: ksam-raw      │
│ Retention: 1 hour   │
└──────────┬──────────┘
           │ Subscribe: ksam.raw.>
           ↓
    Normalizer Worker
           ↓ Publish: ksam.normalized.{type}
┌──────────────────────────┐
│ NATS: ksam-normalized    │
│ Retention: 24 hours       │
└──────┬───────────────────┘
       │
       ├──────────────┬──────────────┐
       │              │              │
       ↓              ↓              ↓
  Risk Worker   Correlator    Policy Engine
  (durable)     (durable)     (future)
```

---

## Consumer Naming Convention

**Format**: `{worker-type}-worker-{instance-id}`

**Examples**:
- `normalizer-worker-0`
- `normalizer-worker-1`
- `risk-worker-0`
- `correlator-worker-0`

**Durability**: All consumers are durable to survive pod restarts

## Stream Configuration

```yaml

  - ksam.raw.>

max_age: 1h
```

## Migration Notes

**Changed** (2025-11-30):
- `ksam.inventory.*` → `ksam.raw.*` (standardized per Architecture Review)
- Stream name: `ksam-inventory` → `ksam-raw`

**Backward Compatibility**: 
- Old consumers will stop receiving messages
- Need to restart workers after deployment

---

## Best Practices

1. **Single Consumer per Stream Stage**: Only Normalizer reads from `ksam.raw.*`
2. **Multiple Consumers for Normalized**: Risk, Correlator, etc. can all read from `ksam.normalized.*`
3. **Durable Consumers**: All workers use durable consumers for reliability
4. **Manual Ack**: Workers use manual acknowledgment for error handling
5. **Subject Wildcards**: Use `>` for subscribing to all subjects in a hierarchy
