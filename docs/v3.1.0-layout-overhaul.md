## 🔍 Problem Statement

User requested: **"Căn chỉnh lại Header (Logo + Project name + Nav + Account). Dùng 1 thanh top-bar chuẩn: Thẳng hàng, Cân trái–giữa–phải, Logo lên đúng góc trái. Dùng Layout 3-cột Flex chuẩn cho Sidebar Filters, Graph Visualization và Node Details: Hai bên Sidebar luôn cùng chiều cao, Graph auto-fill phần giữa, Không bị đè, không bị thừa khoảng trắng."**

### Issues in v3.0.5:
1. **Top Bar**: Sử dụng justify-between, chưa có cấu trúc left-center-right chuẩn
2. **Logo**: Không ở góc trái tuyệt đối
3. **Nav links**: Không ở giữa (center)
4. **Account**: Không ở phải (right)
5. **3-column layout**: Sidebars không cùng chiều cao
6. **Graph container**: Có thể bị đè hoặc thừa khoảng trắng

### 2. **Root Layout Structure**

**File**: `dashboard/src/App.tsx` (AppRoutes)

#### Before (v3.0.5):
```tsx
<div className="min-h-screen bg-gray-50 dark:bg-gray-900">
  {isAuthenticated && <Navigation />}
  <Routes>
    <Route path="/graph" element={<GraphView />} />
  </Routes>
</div>
```

**Problems**:
- ❌ `min-h-screen` → Not using flex layout
- ❌ Routes not constrained → Can overflow
- ❌ No height calculation for content area

#### After (v3.1.0):
```tsx
<div className="flex flex-col h-screen overflow-hidden">
  {isAuthenticated && <Navigation />}
  <div className="flex-1 overflow-hidden">
    <Routes>
      <Route path="/graph" element={<GraphView />} />
    </Routes>
  </div>
</div>
```

**Benefits**:
- ✅ **flex flex-col** → Vertical stack
- ✅ **h-screen** → Full viewport height
- ✅ **Navigation** fixed at top
- ✅ **flex-1 overflow-hidden** → Content fills remaining space
- ✅ No scrollbars on root level

---

### 3. **GraphView 3-Column Layout**

**File**: `dashboard/src/pages/GraphView.tsx`

#### Before (v3.0.5):
```tsx
<div className="flex h-full w-full overflow-hidden">
  <div className="w-80 h-full flex-shrink-0">
    <Filters />
  </div>
  
  <div className="flex-1 flex flex-col h-full overflow-hidden">
    <Graph />
  </div>
  
  <div className="w-80 h-full flex-shrink-0">
    <Details />
  </div>
</div>
```

**Problems**:
- ❌ Redundant `h-full` on children (parent already `h-full`)
- ❌ Can cause height calculation conflicts
- ❌ Sidebars may not stretch properly

#### After (v3.1.0):
```tsx
<div className="flex h-full w-full overflow-hidden">
  <div className="w-80 flex-shrink-0">
    <Filters />
  </div>
  
  <div className="flex-1 flex flex-col overflow-hidden">
    <Graph />
  </div>
  
  <div className="w-80 flex-shrink-0">
    <Details />
  </div>
</div>
```

**Benefits**:
- ✅ Removed redundant `h-full` from children
- ✅ Parent `flex` automatically stretches children to same height
- ✅ `flex-shrink-0` ensures sidebars maintain width
- ✅ `flex-1` ensures graph fills remaining space
- ✅ No conflicts, no overflow issues


**Calculation**:
- Screen width: 1920px
- Sidebar: 320px (fixed)
- Panel: 320px (or 0px when closed)
- **Graph**: `1920 - 320 - 320 = 1280px` (auto-calculated by flex-1)

## 🔍 Key CSS Concepts

### 1. **Grid cols-3 for Top Bar**

```css
.grid-cols-3 {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
```

- Each column gets equal width (33.33%)
- Content in each column can use `justify-start`, `justify-center`, `justify-end`
- Perfect for left-center-right alignment

---

### 2. **Flex Container Height**

```tsx
<div className="flex h-full">
  <div className="w-80">Sidebar</div>
  <div className="flex-1">Graph</div>
  <div className="w-80">Panel</div>
</div>
```

**What happens**:
1. Parent `flex` with `h-full` → Takes full height of its parent
2. All children (Sidebar, Graph, Panel) → Automatically stretch to match parent height
3. No need for `h-full` on children!

---

### 3. **flex-1 Auto-Fill**

```css
.flex-1 {
  flex: 1 1 0%;
}
```

**Means**:
- `flex-grow: 1` → Grow to fill available space
- `flex-shrink: 1` → Can shrink if needed
- `flex-basis: 0%` → Start from 0, then grow

**Result**: Graph canvas fills all remaining space after sidebars take their fixed width.

---

### 4. **flex-shrink-0 Fixed Width**

```css
.flex-shrink-0 {
  flex-shrink: 0;
}
```

**Means**:
- Sidebars maintain their width (320px)
- Won't shrink even if space is tight

## 💡 Key Architectural Decisions

### 1. **Why Grid cols-3 for Top Bar?**

**Alternative**: Flex with space-between + individual positioning
```tsx
<div className="flex justify-between">
  <div>Logo</div>
  <div>Nav</div>
  <div>Account</div>
</div>
```

**Problem**: Nav not truly centered (depends on Logo and Account widths)

**Solution**: Grid cols-3 gives each section equal width, ensuring perfect center alignment regardless of content size.

---

### 2. **Why Remove h-full from Children?**

**Alternative**: Explicitly set `h-full` on all children
```tsx
<div className="flex h-full">
  <div className="h-full">Sidebar</div>
  <div className="h-full">Graph</div>
  <div className="h-full">Panel</div>
</div>
```

**Problem**: Can cause height calculation conflicts and nested 100% issues.

**Solution**: Flex container automatically stretches children to match its height. No explicit height needed on children!

---

### 3. **Why flex-1 for Graph?**

**Alternative**: Calculate width with CSS calc()
```tsx
<div style={{ width: 'calc(100% - 640px)' }}>Graph</div>
```

**Problem**: Doesn't adapt when sidebars collapse/expand.

**Solution**: `flex-1` automatically fills remaining space, adapting to sidebar state changes.
