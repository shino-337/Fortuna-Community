## 🔧 What's Fixed

### 1. **Larger, More Visible Nodes**

**Problem**: Nodes too small (5-12px radius)  
**Solution**: Increased all node sizes by 60-100%

| Node Type | v3.0.1 | v3.0.2 | Increase |
|-----------|--------|--------|----------|
| Cluster | 12px | 20px | +67% |
| Namespace | 10px | 16px | +60% |
| ServiceAccount | 8px | 14px | +75% |
| Role/ClusterRole | 7px | 12px | +71% |
| Bindings/Pods | 6px | 10px | +67% |

### 2. **Thicker, More Visible Edges**

**Problem**: Edges too thin (1.5px), hard to see  
**Solution**: Increased edge thickness and arrow size

```typescript
// Before
ctx.lineWidth = 1.5 / globalScale
arrowLength = 10 / globalScale

// After
ctx.lineWidth = Math.max(2, 2.5 / globalScale)  // +67% thicker
arrowLength = Math.max(12, 15 / globalScale)    // +50% larger arrows
```

### 3. **Better Label Readability**

**Improvements**:
- **Font size**: 12px → 14px minimum
- **Font weight**: 400 (regular) → 600 (semi-bold)
- **Background**: Added white background box for contrast
- **Padding**: 4px padding around text

```typescript
// Label with background for contrast
ctx.fillStyle = 'rgba(255, 255, 255, 0.9)' // White background
ctx.fillRect(x, y, width, height)          // Draw background
ctx.fillStyle = '#1f2937'                  // Dark text
ctx.fillText(label, x, y)                  // Draw text
```

### 4. **D3 Layout Options (Replaced Cytoscape)**

**Removed Cytoscape layouts**:
- ❌ COSE, FCOSE, Dagre, Breadthfirst, Circle, Concentric, Grid

**Added D3 layouts**:
- ✅ **Force-Directed** (default) - Physics-based attraction/repulsion
- ✅ **Radial** - Nodes arranged in concentric circles
- ✅ **Tree** - Hierarchical top-down layout (DAG mode)
- ✅ **Grid** - Static grid arrangement (no physics)

```typescript
// Layout-specific settings
cooldownTicks={layout === 'grid' ? 0 : 100}
d3AlphaDecay={layout === 'force' ? 0.02 : 0.05}
dagMode={layout === 'tree' ? 'td' : undefined}
```

### 5. **Container Sizing Fixed**

**Problem**: `force-graph-container` using wrong dimensions  
**Solution**: Dynamic dimension tracking with ResizeObserver

```typescript
const [dimensions, setDimensions] = useState({ width: 800, height: 600 })

useEffect(() => {
  const updateDimensions = () => {
    const width = containerRef.current.offsetWidth
    const height = containerRef.current.offsetHeight
    if (width > 0 && height > 0) {
      setDimensions({ width, height })
    }
  }
  
  window.addEventListener('resize', updateDimensions)
  const resizeObserver = new ResizeObserver(updateDimensions)
  resizeObserver.observe(containerRef.current)
}, [])

// Use computed dimensions
<ForceGraph2D width={dimensions.width} height={dimensions.height} />
```

## 🏗️ Layout Options

### 1. Force-Directed (Default)
- **Best for**: General graphs, small-medium datasets
- **Physics**: Nodes repel, edges attract
- **Animation**: Smooth settling over ~2 seconds
- **Settings**: `d3AlphaDecay: 0.02`, `d3VelocityDecay: 0.3`

### 2. Radial Layout
- **Best for**: Hierarchical data, star patterns
- **Physics**: Faster settling
- **Animation**: Nodes arrange in concentric circles
- **Settings**: `d3AlphaDecay: 0.05`, `d3VelocityDecay: 0.4`

### 3. Tree Layout
- **Best for**: Directed graphs, dependencies
- **Physics**: No physics, pure hierarchy
- **Animation**: Top-down directed acyclic graph
- **Settings**: `dagMode: 'td'`, `dagLevelDistance: 150`

### 4. Grid Layout
- **Best for**: Static view, screenshots
- **Physics**: None (cooldownTicks: 0)
- **Animation**: Instant placement
- **Settings**: Nodes arranged in grid pattern

## 📝 Migration Notes

### From v3.0.1
- **No breaking changes**
- Layout prop still accepted (but values changed)
- Old layout values ('fcose', 'cose') will default to 'force'
- No API changes

### Layout Value Mapping
```typescript
// Old (Cytoscape) → New (D3)
'cose' | 'fcose' → 'force'
'dagre'          → 'tree'
'breadthfirst'   → 'radial'
'grid'           → 'grid'
'circle'         → 'radial'
'concentric'     → 'radial'
```

## 🐛 Known Issues

### Issue: Text overlap on dense graphs
**Workaround**: Use zoom or reduce visible nodes with filters

### Issue: Initial layout may be chaotic with many nodes
**Workaround**: Wait 2-3 seconds for physics to settle, or use Grid layout

### Issue: Tree layout requires directed graph
**Status**: Works best when graph has clear hierarchy (e.g., Cluster → Namespace → SA)
